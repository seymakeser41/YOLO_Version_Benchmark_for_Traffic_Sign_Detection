# YOLO_Version_Benchmark_for_Traffic_Sign_Detection
Project Overview
This project presents a benchmark comparison of multiple YOLO architectures for traffic sign detection.

The following YOLO models are compared:
YOLOv10
YOLOv11
YOLOv12
YOLOv13
YOLOv26

All models are trained and evaluated on the same traffic sign dataset to ensure a fair comparison.
